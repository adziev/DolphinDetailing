# Извештај за проверка

Датум: 17.10.2026. Локален HTTP сервер, Chromium во вградениот прелистувач на Codex. Не е тестиран или објавен продукциски deployment.

## Автоматски проверки

- 36 HTML страници: постојат соодветни `lang` вредности, еден `h1`, уникатни IDs и описи на сликите.
- 1.166 локални референци кон HTML, фотографии, CSS и JS: **0 непостоечки фајлови**.
- JavaScript syntax проверка: **помина**.
- Responsive: почетна, услуги, галерија, контакт, тим, блог листа, еден цел блог-текст и англиска почетна, на ширини **320, 390, 768 и 1280 px**, висина 844 px: **32/32 проверки без хоризонтално прелевање**.
- Целосните responsive резултати: [layout-results.json](layout-results.json).

## Проверени интеракции во прелистувач

- Галерија: „Нашето студио“ ги остава двата релевантни кадра; клик отвора модален преглед со слика и опис; Escape го затвора.
- Мобилно мени: отворање го менува `aria-expanded` во `true`; Escape го затвора и ја враќа вредноста во `false`.
- Услуги: отворање детали прикажува вклучени постапки.
- Македонски → англиски: од услугите се отвора англиската страница со соодветниот наслов.
- Consent: „Само неопходни“ го крие известувањето и изборот опстојува при навигација. Повторното отворање од подножјето работи.
- Дозвола за поставки → светла тема → reload: темата останува светла.
- Потоа „Само неопходни“ → reload: зачуваната тема е отстранета и се враќа основната темна тема.
- Демо форма: валидно име, е-пошта, порака и означено поле прикажуваат **„НЕ е испратено“** и линк за преземање.
- Преземениот `.txt` е прочитан: ги содржи точните тест-податоци и ознака DEMO / НЕ Е ИСПРАТЕНО.
- Невалидна е-пошта ја блокира валидацијата; при измена на внесот претходниот линк за преземање се повлекува.
- Во прегледаниот browser log нема JavaScript errors или warnings.
- Screenshots: [desktop.png](desktop.png), [mobile.png](mobile.png).

## Ограничувања и рачна проверка пред предавање

- Не е направено целосно тестирање во Safari, Firefox или на физички телефони. Responsive тестовите се во еден browser engine.
- Статичката проверка не е целосен W3C валидатор или автоматизирана accessibility ревизија.
- Нема реално испратена порака, е-пошта, резервиран термин или backend интеграција. Тоа е намерно демонстрациска форма.
- Надворешните линкови за телефон, мапи и социјални мрежи се пренесени од оригиналот; не се тестирани со вистински повик или испраќање порака.
- Без JavaScript се достапни HTML страниците, содржината, деталите за услуги и директните линкови до сликите. Демо формата и JS контролите се скриени преку `noscript`; не е извршена посебна browser сесија со исклучен JavaScript.
- Нема потврдени лични податоци за тимот или целосни официјални критериуми на предметот. Додадете ги реалните студентски податоци пред предавање ако се задолжителни.
- Не е направено RepoRun поставување. По последната насока, споделувањето е преку GitHub, а предавањето/хостирањето ќе го направите рачно.
- Сликите се локални и во оригинална резолуција. Не е извршено мерење на Lighthouse/performance на мобилна мрежа.
