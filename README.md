# Dolphin Detailing — ФИНКИ

Студентска преработка за предметот **Деловна пракса**, со **HTML5, CSS3 и vanilla JavaScript**. Нема React, Next.js, Tailwind, npm, build процес, CDN библиотеки или база на податоци. Фајловите се готови за статички веб сервер.

Извор: приватниот [Mustak4/DolphinDetailing](https://github.com/Mustak4/DolphinDetailing), гранка `master`, commit `da76420e2cd0737f957b2657214ecb356d6d373f`, и [живиот сајт](https://dolphindetailing.mk/), прегледани на **17.10.2026**. Оригиналниот репозиториум и продукцискиот сајт не се изменети. Овој проект е независен и не се поврзува со нивниот backend.

## Што е направено

- Почетна со оригиналната фотографија на студиото, логото, црвени акценти и темна/светла тема.
- Посебни страници: за нас, услуги, галерија, тим, блог, контакт и приватност.
- Пет оригинални услуги со детали преку HTML `details`/`summary`.
- Галерија со 37 оригинални фотографии, седум филтри (вклучувајќи „Сите“) и достапен модален преглед со Escape и враќање на фокусот.
- Десет оригинални блог-текста со фотографии и FAQ каде што постои во изворот.
- Сите 18 страници на македонски и англиски: **36 HTML фајлови**. Префрлањето јазик ја отвора соодветната страница, вклучувајќи го истиот блог-текст.
- Responsive приказ, мобилно мени, означена активна страница, labels на формата, keyboard focus и поддршка за reduced motion.
- Cookie consent со „Само неопходни“, избор за зачувување поставки и повторно отворање од подножјето. Не се вчитуваат Google Maps iframe, аналитика или рекламни скрипти.
- Оценката 5.0 и бројот 63 рецензии се јасно означени како пресек од живиот сајт, не како тековни API податоци.

Навигацијата и подножјето се повторени во секоја страница намерно, за едноставна структура без framework; при нивна промена треба да се ажурираат во сите страници.

## Локално стартување

Најлесно: отвори `index.html` во прелистувач. Линковите, сликите и основната содржина користат релативни патеки. Однесувањето на localStorage на `file://` адреси зависи од прелистувачот, па за consent и зачувување тема користи локален HTTP сервер.

Ако имаш Python 3, во папката на проектот изврши:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

На Windows може `py -m http.server 8000 --bind 127.0.0.1`.

Отвори **http://127.0.0.1:8000/**. Англиски: **http://127.0.0.1:8000/en/index.html**. За стопирање: `Ctrl+C`. Python служи само за локален преглед и опционални проверки; не е дел од веб-страницата и не испраќа е-пошта.


## Контакт формата и backend

**Ова е демонстрациска форма и НЕ испраќа пораки.** Тоа е напишано и во самиот интерфејс. Таа:

1. Проверува задолжителни полиња, формат на е-пошта, минимални и максимални должини.
2. Бара потврда дека корисникот разбира дека не се испраќа порака.
3. При валиден внес создава локален `.txt` фајл преку `Blob` за преземање.
4. Не испраќа HTTP POST, не чува лични податоци во localStorage и не прикажува „успешно испратено“.
5. При измена на внесот го повлекува претходниот линк за преземање, за да нема застарено барање.

Вистинско испраќање бара посебен backend или конфигуриран доверлив form сервис, потврдена адреса на примачот, серверска валидација, заштита од spam и соодветна политика за обработка на податоци. Не ставај SMTP лозинки, API тајни или service keys во JavaScript. Не е измислена адреса на е-пошта; вистински контакт е оригиналниот телефон **+389 70 684 638** и Instagram. Со исклучен JavaScript демо формата е скриена за да се избегне случајно GET испраќање на лични податоци.

## Тестирање и одржување

```sh
python3 tools/check_site.py
```

Проверката користи само стандардна Python библиотека: локални линкови, слики, CSS/JS патеки, `lang`, еден `h1` и уникатни HTML IDs. Не е целосен W3C validator. За резултатите од browser тестовите и нивните ограничувања види [docs/TESTING.md](docs/TESTING.md).

За промена на текст: отвори го соодветниот `.html` и англискиот пар во `en/`. За нов блог: копирај постоен `blog-*.html` во двата јазика, смени наслов, содржина, фотографија и language link, па додади картички во двете `blog.html` страници. Сликите се оригинални и локални, со задржана резолуција; вкупната големина на сајтот е приближно 62 MB. За продукциско оптимизирање може да се подготват помали responsive фотографии.

Логото, фотографиите и текстовите потекнуваат од Dolphin Detailing и се пренесени на барање на сопственикот на GitHub сметката во приватен студентски проект. Ова не е изјава дека средствата имаат open-source лиценца или дека се слободни за туѓа комерцијална употреба.
